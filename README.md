# LockIt : Aesthetic, Research-Backed Pomodoro & Deep Work Hub

> **Made with precision and heart by Allen Benny.**
> *A minimalist, ultra-responsive study and focus sanctuary designed for deep work, cognitive flow, and mindful productivity.*

---

## Overview

**LockIt** is an ultra-modern Progressive Web App (PWA) that blends tactile, water-like fluid interactions, warm terracotta & soft pastel editorial aesthetics, biophilic soundscapes, habit analytics, and an intelligent AI study companion into a distraction-free environment.

Installable with 1 click on desktop and mobile browsers, LockIt operates **100% offline**, keeps your focus data private on your device, and replaces anxiety-inducing ticking countdowns with soothing, organic flow states.

---

## Core Features

### 1. Fluid Water-Like Aesthetics & Calming Interactions
- **Living Water Waves**: Real-time canvas physics with dual-layer fluid tides that gently rise as you progress through your session.
- **Clock Dial & Tick Arc**: Elegant curved tick dial inspired by precision horology.
- **Tactile Squishy Controls**: Smooth spring physics on every button, priority card, and tab.
- **Dynamic Personalized Encouragement**: Tailored motivational nudges addressing you by name (*"Focus on a process, Allen!"*, *"Come on, Allen 🤗"*, *"Take a break, Allen! ☕"*).

### 2. 4 Curated Editorial Visual Themes
- **Terracotta & Cream (Minimalist)**: Earthy clay terracotta `#C86246`, warm almond milk cream `#FAF6F0`, deep charcoal pill contrast.
- **Pastel Campus (Joyful)**: Cheerful butter yellow `#FFC93C`, soft lilac cards `#F5F4FD`, and rounded playful geometry.
- **Liquid Violet & Coral (Immersive)**: Deep royal violet `#3F2B7B` with vibrant sunset coral `#FA5246` and organic fluid curves.
- **Midnight Zen (OLED Dark)**: Pure obsidian black `#0E1015` with glowing amber `#F59E0B` for late-night deep work sessions.

### 3. Built-in Procedural Biophilic Soundscapes & NCS Lofi Player
- **Zero Copyright & 100% Offline Procedural Synthesizers** (Web Audio API):
  - **Deep Brown Noise**: Low-frequency acoustic blanket proven to silence ADHD mind-wandering.
  - **Pink Noise ($1/f$)**: Synchronizes slow-wave brain rhythms for sustained retention.
  - **Gentle Rainfall & Droplets**: Randomized droplet physics on a quiet study window.
  - **Ocean Tide Waves**: 8-second rhythmic sine-modulated tides for paced breathing.
  - **Mountain Forest Stream**: Trickling alpine brook for cognitive restoration.
  - **432Hz Tibetan Singing Bowl Drone**: Theta-wave resonant drone for reading and meditation.
  - **Peaceful Zen Completion Chimes**: Harmonious Solfeggio bell frequencies upon session completion.
- **NCS & Lofi Relax Beats**: Built-in copyright-free chill study stream + live animated audio waveform visualizer + support for custom audio links.

### 4. Priority Deck & High-Impact Project Organizer
- **Priority Selector (1, 2, 3, Add)**: Organize and tackle tasks strictly by cognitive impact.
- **Estimated Pomodoro Tracking**: Track planned vs. completed focus intervals per goal.
- **Project Categories**: Custom color-coded tags (*Deep Focus, Research & Study, Creative Build, Reading*).

### 5. Analytics, Streaks & Habit Heatmap
- **Today & All-Time Focus Log**: Total completed sessions and cumulative hours locked in.
- **"THIS WEEK" Bar Chart**: Animated daily focus distribution.
- **Monthly Habit Heatmap**: Visual 28-day consistency grid tracking deep work density.
- **Consecutive Streak Counter**: Flame streak tracker to maintain momentum.

### 6. Research-Backed Cognitive Architecture
- **Attention Restoration Theory (Kaplan & Kaplan)**: Replaces red cortisol-inducing timers with soft fascination.
- **Ultradian Pacing (Kleitman)**: Presets for 25m Classic, 50m Deep Work, 90m Flow Sprint, or 15m Quick Start.
- **Implementation Intentions (Gollwitzer)**: Quick micro-action input before starting creates immediate neural commitment.
- **Zen Mode**: Option to hide ticking seconds to prevent clock-watching anxiety.

### 7. Progressive Web App (PWA) & Offline Capabilities
- Installable on Google Chrome, Microsoft Edge, macOS, Android, and iOS Safari.
- Offline-ready via dedicated Service Worker and Web App Manifest.
- Zero tracking, zero telemetry, GDPR-friendly local storage.

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `Space` | Start / Pause Timer |
| `R` | Reset Current Session |
| `S` | Skip to Next Phase (Focus / Break) |

---

## Technology Stack

- **Framework**: React 18 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4 + Custom Keyframe Physics
- **Motion & Interactions**: Framer Motion
- **Sound Synthesis**: Native Web Audio API (AudioContext, BiquadFilter, Oscillator, GainNode)
- **Icons**: Lucide React
- **Celebration**: Canvas-Confetti
- **PWA**: Service Worker Cache API + Web Manifest

## Getting Started

```bash
# Clone the repository
git clone git@github.com:officiallygod/LockIt.git
cd LockIt

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
